# 操作日志记录功能

## 功能介绍

该功能用于记录用户与LLM交互的操作历史，主要特点：

- 异步发送日志，不影响主业务流程
- 记录用户输入、使用的模型、操作模式等信息
- 前端调用后无需等待结果

## 接口说明

日志数据将被发送到以下接口：
- 路径：POST https://aab.haier.net/gateway/api-aab/aab/api/operation-log
- 请求体格式：
```json
{
    "operator": "用户姓名(工号)",
    "inputParams": "{\"key\":\"value\"}",
    "mode": "操作模式", 
    "prompt": "用户提示词",
    "llmModel": "使用的AI模型"
}
```

## 字段说明

- `operator`: 操作用户信息，格式为"姓名(工号)"，从当前登录用户信息中获取。若未登录则为'anonymous'
- `inputParams`: 包含系统提示词和交互历史（JSON字符串）
- `mode`: 操作模式，如"normal"或"rag"
- `prompt`: 用户输入的提示词
- `llmModel`: 使用的AI模型ID

## 用户信息获取

- 系统会自动从已登录用户信息中获取用户姓名和工号
- 若工号和姓名都存在，则格式为"姓名(工号)"
- 若只有姓名，则只使用姓名
- 若未登录，使用默认值'anonymous'

## 注意事项

- 日志服务采用异步方式，不会影响主业务流程
- 连接失败或其他错误不会影响正常的LLM交互
- 日志内容仅包含交互数据，不会保存具体的代码内容
